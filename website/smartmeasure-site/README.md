# SmartMeasure Pro — Project Site

## Structure
```
smartmeasure-site/
├── index.html
├── css/style.css
├── js/script.js
├── assets/
│   ├── images/    ← device & app screenshots go here
│   ├── videos/    ← demo clips go here
│   └── team/      ← team member photos go here
└── README.md
```

## Run locally
Open this folder in VS Code, install the **Live Server** extension, right-click
`index.html` → "Open with Live Server."
